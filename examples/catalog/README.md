# Regression catalogs

> [!CAUTION]
> These catalogs supply test identities and discovery data for the training fixtures. They are
> not the live project, product, sourcing, team or release catalogs for your work.

The repository's live shared catalogs are under [`../../catalog/`](../../catalog/README.md).
Template adoption clears example entries from live discovery while retaining these files for
independent fixture checks. Keep actual project decisions in the root catalogs or in the owning
board's `projects/<id>/` island, as described in the
[repository structure guide](../../docs/workflow/REPOSITORY_STRUCTURE.md).
