# Shared training libraries

> [!CAUTION]
> Libraries under this folder support the training fixtures. Their symbols, footprints and part
> bindings are not qualified for a real design, purchase or physical fit.

The [status-LED library](status-led/README.md) is declared only by the Arduino and Raspberry Pi
training projects. For real boards, use an explicitly reviewed dependency and provenance record;
see the [shared-library policy](../../docs/workflow/LIBRARIES.md). Keep project-specific CAD in
the owning board island rather than borrowing assets from these examples.
