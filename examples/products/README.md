# Product training fixtures

> [!CAUTION]
> Products under this folder are training-only integration examples. Their assemblies, variants,
> wiring, sourcing and mechanical notes are not approved product definitions, fit evidence or
> manufacturing records.

The [reference status-indicator system](status-indicator-system/README.md) shows how board
islands can be grouped. For an adopted project, create a product record under
[`../../products/`](../../products/README.md) only when real integration requirements need one.
Read the [examples index](../README.md) for the fixture boundary and the
[product workflow](../../docs/workflow/PRODUCT_WORKFLOW.md) before creating a real record.
