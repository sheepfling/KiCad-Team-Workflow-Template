# Project training fixtures

> [!CAUTION]
> Every project under this folder is a training fixture marked `training_fixture` and
> `training`. The board, schematic, requirements, part identities and tests are examples, not
> approved engineering inputs or manufacturing data.

Use [the examples index](../README.md) to choose a rehearsal. For a real board, create a new
island under [`../../projects/`](../../projects/README.md) and follow the
[first-board workflow](../../docs/workflow/FIRST_BOARD.md) or
[import workflow](../../docs/workflow/IMPORT_WORKFLOW.md). Keep these fixtures as regression
inputs; do not rename or modify one to hold project work.
